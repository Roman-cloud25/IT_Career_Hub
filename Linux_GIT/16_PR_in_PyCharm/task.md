Работаем с репозиторием https://github.com/it-career-hub/learning_git 
1. Сделайте форк этого репозитория (если не делали ранее). 
2. Склонируйте  его на локальный компьютер или сделайте pull. 
Работаем в Pycharm!
3. Создайте папку с именем Вашей группы, если такой еще не создано. 
4. Создайте ветку с вашим именем и HW16 (например andrew-hw16) и переключитесь на нее.
5. В директории с именем Вашей группы создайте любой файл с вашим именем (без личных данных, репозиторий публичный). 
6. Выполните коммит, push и откройте PR в репозиторий https://github.com/it-career-hub/learning_git с этими изменениями
из Вашего репозитория и из ветки (которую вы создали в пункте 5)


Working with the repository https://github.com/it-career-hub/learning_git
1. Fork this repository (if you haven't already).
2. Clone it to your local computer or pull it.
Working in Pycharm!
3. Create a folder with your group's name, if one doesn't already exist.
4. Create a branch with your name and HW16 (for example, andrew-hw16) and switch to it.
5. In the directory with your group's name, create any file with your name (no personal information, the repository is public).
6. Commit, push, and open a PR to the repository https://github.com/it-career-hub/learning_git with these changes 
from your repository and from the branch (which you created in step 5).
