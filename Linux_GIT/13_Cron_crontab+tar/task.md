2. Скрипт должен создавать по 10 файлов с порядковым номером и датой создания. 1_20.04.23 , 2_20.04.23 , 3_20.04.23 .. 10_20.04.23

4. Создайте архив с файлами из п2. , добавьте в него историю команд, которую вы выполнили. 
5. Закомментируйте строку с заданием в планировщике (добавьте # в начало строки с вашим заданием), чтобы выключить задание, но оставить его “в быстром доступе”


1. Create a folder with your name on the server. In the folder with your name, create a script called task_NAME.sh, where NAME is your name.
2. The script should create 10 files with a sequential number and creation date. 1_20.04.23, 2_20.04.23, 3_20.04.23... 10_20.04.23
3. Create a new task in the scheduler that will run your script every 15 minutes.
4. Create an archive with the files from p2. , and add the command history you've executed to it.
5. Comment out the task line in the scheduler (add # to the beginning of the line with your task) to disable the task but keep it "quickly accessible."
