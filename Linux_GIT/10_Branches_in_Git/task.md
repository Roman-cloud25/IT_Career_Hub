1. Create a new repository in Github named git-branch
2. Initialize a local repository with the same name
3. Create and switch to the new gitignore branch
4. Add a .gitignore file to the project, such as https://github.com/aliaskov/bashscripts/blob/master/.gitignore
5. Make a commit and push it with the gitignore branch to the git-branch repository
