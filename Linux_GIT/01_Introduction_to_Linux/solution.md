1. What is the difference between the /bin and /sbin folders in the Linux root directory?
/bin contains essential system files accessible to all users.
/sbin contains system files accessible by root.
2. What happens if I create a file or folder in Linux with the same name but different case? (For example, Folder and FOLDER)
Nothing will happen. Linux allows creation of files with the same name but different case.
3. What is the name of the temporary folder in Linux and Windows?
Linux - tmp
Windows - Temp
4. Why are there so many versions of Linux?
There are so many Linux versions because it is open source and free, and everyone creates their own distribution to suit their needs.
5. What is the purpose of the /opt folder located in the root directory?
Third-party software that is not considered standard in Linux is installed in the /opt folder.
6. What is the purpose of a command shell?
The command shell is used to enter commands and display the results.
7. What is an OS kernel?
The OS kernel is the main part of the OS and acts as an intermediary between the computer's hardware and all programs.
8. Name several operating systems that run the Linux kernel.
Ubuntu, Debian, Android, Fedora, Linux Mint
