1. Log in to the training server at linux.itcareerhub.de
2. Declare a new system variable, ANDREW_VARIABLE, and assign it a value with the name of your group, where ANDREW is replaced with your name.
3. Create a hidden file, process_management, at the full path /opt/YOUR_GROUP/YOUR_NAME. In this file:
Write the date
Add "Welcome to Amazon server" - in any convenient way
Add information about the total amount of RAM - in any convenient way
Add information from the process list, but from the output of the entire command, only extract the NUMBER of processes running under the root user.
Add information about the declared variables, but filter them so that only your variable from step 2 remains (in the example, ANDREW_VARIABLE)
* PID and PPID of the "/usr/sbin/sshd -D" process in the form
PID *** PPID *, where *** and * These are the current process IDs and parent process IDs.
